Enter your requirements (item, qty, event day + GR combination). The system finds the cheapest vendor for each item, using the Item ID to match offers across vendors. Because prices per combination are sparse, the system automatically uses the closest available combination (marked "≈") when the requested combination has no exact data for that vendor. Prices are adjusted proportionally if the requested qty differs from the qty per listing.
